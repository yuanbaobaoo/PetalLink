# PetalLink v1.1.15

## 修复

- **冲突提示在冲突实际解决后永久残留**：冲突处理成功后基线状态停留在「冲突」，即使本地与云端内容早已一致，界面右上角也一直挂着「⚠ 冲突 1」且没有任何入口可以消除。现在每个可信同步周期会自动复核冲突基线：当云端权威身份与版本均未再变化、本地文件与基线快照一致、且该路径没有进行中的传输时，状态自动收敛回「已同步」，提示随之消失。云端或本地只要又出现过变化，则不收敛、照常走冲突/规划流程。
- **应用内更新后客户端退出但没有重新拉起**：Tauri 内置重启在 macOS 上直接 spawn 新进程，更新刚替换完 `.app` 时这一步可能静默失败（错误只进标准错误流，日志中毫无痕迹），进程照常退出，表现为「更新后应用关闭了却没有自己打开」。现在重启前会先调度一个独立的延迟拉起器：旧进程退出后约 1.5 秒经系统 `open` 启动应用（与手动双击打开等价），与内置路径互为保险；拉起失败也会记录到日志。开发模式（非 `.app` bundle 运行）不受影响。

## 工程

- 新增冲突收敛回归测试 3 项（已解决收敛 / 云端已变不收敛 / 本地已改不收敛）。

## 说明

- 平台与校验同 v1.1.14：macOS（Apple Silicon）与 Linux x86_64 AppImage 均支持应用内自动更新，全部资产附 SHA256SUMS 与 minisign 签名。
- 若 v1.1.14 更新后应用未自动打开，属本版修复范围内的已知缺陷；手动打开一次即可，更新到本版后重启行为恢复正常。
