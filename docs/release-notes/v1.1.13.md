# PetalLink v1.1.13

## 修复

- **Linux AppImage 内的 `.DirIcon` 与根目录 `.desktop` 此前是悬空软链接**：旧版打包器把两者生成成指向构建机上绝对路径的符号链接，镜像内原样保留后在其他机器上均无法解析——文件管理器与应用目录显示不出图标，部分 AppImage 安装器（如 AppManager）无法识别。现随打包器升级改为相对软链接。
- 该缺陷曾阻塞 AppImage 官方应用目录（appimage.github.io）的自动收录测试，本版本起恢复可收录状态。

## 工程

- `@tauri-apps/cli` 由 2.11.3 升级至 2.12.0（lockfile 同步更新）。仅影响打包产物，不涉及应用代码改动。

## 说明

- 平台与校验同 v1.1.12：macOS（Apple Silicon）与 Linux x86_64 AppImage 均支持应用内自动更新，全部资产附 SHA256SUMS 与 minisign 签名。
