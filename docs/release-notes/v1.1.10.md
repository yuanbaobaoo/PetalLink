# PetalLink v1.1.10

## 修复

- **同名文件冲突不再死循环**：上传前检测到目标目录已有同名远端文件时，现在会校验内容一致性——同名同内容（SHA-256 或大小+创建窗口证明）直接采纳云端文件并完成同步，不再重复上传；确实同名不同内容时，任务进入「同名冲突」状态等待处理，不再出现「重新检查」点多少次都消不掉的问题。
- **上传确认更可靠**：兼容华为云盘接口把文件大小返回为字符串的响应变化（2026-09 起出现），修复因此导致的「上传 100% 后一直停在确认结果」。此前因歧义滞留的任务升级后可自动核验收敛。
- **释放空间弹窗展示文件路径**：候选项由文件名改为相对路径（如 `a/b/c/d.txt`），弹窗加宽，长路径支持横向滚动，释放前能看清文件位于哪个目录。

## 新增

- **同名冲突的三种处理方式**（传输队列任务行「更多操作」菜单）：
  - 覆盖远端：云端现有版本自动改名为「原名 (云端副本 时间戳)」保留，再用本地文件重新上传——不丢任何数据；
  - 保留两者：本地文件改名为「原名 (本地副本 时间戳)」后作为新文件上传，云端原文件不动；
  - 取消任务：不再同步该文件。
- 「需要重新检查」和失败的任务现在可以手动取消。

## 平台

- macOS（Apple Silicon）：`.dmg` 安装包，支持应用内自动更新。
- Linux（x86_64）：官方 `.AppImage`，支持应用内自动更新（AUR/Deb 等包管理器安装请用各自渠道更新）。

## 校验

- 全部资产附 SHA256SUMS；更新包带 minisign 签名，应用内更新自动验签。
