# PetalLink v1.1.12

## 修复

- **设置页「保存设置」此前永远无法点击**：表单修改后按钮保持禁用，只能绕经选择目录顺带提交；现在编辑任一配置项即可保存。
- **传输并发数步进器的减号此前显示成了加号**：减号按钮误用「×」图标旋转 45°（视觉上是「+」），已改为真正的减号。
- **登录授权回调更健壮**：修复回调请求被 TCP 分包截断、以及浏览器 favicon 预检请求抢先占用唯一回调机会的问题。
- **PKCE 调试输出不再泄露授权凭据**：code_verifier 在 Debug 日志中同样隐藏。
- **批量删除确认不再逐个文件串行查询状态**：直接复用列表已拉取的批量状态，多选大量文件时确认框即时弹出。
- **切换文件列表排序方式不再触发整目录状态重拉**：切换目录时缩略图与状态缓存也会正确清理，避免内存只增不减。
- **确认对话框并发打开不再让前一个调用方永久等待**：被覆盖的旧确认框按「取消」收尾。
- **更新对话框「后台等待」不再被违逆**：关闭对话框即取消传输等待轮询，超时也不会被强制弹回。
- **大批量本地变更事件去重提速**：文件监视器的待发布路径去重从 O(n²) 改为哈希集合。
- **按需下载的内部锁表不再随会话无限增长**：水合完成后自动修剪条目。
- **Linux 按需云盘下载不再冻结整个挂载点**：此前下载期间新建/删除/改名都会卡住，现在下载与命名空间操作可并发。

## 内部改进

- 云端同步检查点的四组锁收敛为单一互斥状态，安装从可撕裂的多步操作变为原子替换。
- 「路径是否被活动传输占用」等安全判定从多份重复实现收敛为唯一实现。
- 传输重试退避、401 认证重放、上传源快照核验等共享逻辑收敛到单处。
- 配置文件的磁盘格式改用类型化镜像结构承载，并新增金样测试锁定兼容合同。
- 命令层与全局运行时分离；FUSE 挂载能力探测与配置存储分层归位。
- 前端同步/传输状态改为单一权威快照加派生计算，消除逐字段赋值漂移。

## 工程

- 新增 Linux CI：每次推送与 PR 自动运行 Rust 测试、clippy 与前端测试。

## 说明

- 平台与校验同 v1.1.11：macOS（Apple Silicon）与 Linux x86_64 AppImage 均支持应用内自动更新，全部资产附 SHA256SUMS 与 minisign 签名。
