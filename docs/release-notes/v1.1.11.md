# PetalLink v1.1.11

## 修复

- **「需要重新检查」的任务可真正重试**：此前同名文件冲突导致的滞留任务，点「重新检查」只触发后台重新规划，而规划器对「本地和云端都有、但无同步记录」的路径只会跳过，任务永远等不到重规划、永远消不掉。现在重试会直接重新执行上传，依据云端实时状态自动收敛：同名同内容直接采纳云端文件完成同步；同名不同内容进入「同名冲突」状态，可在任务行菜单选择覆盖（旧版保留副本）/保留两者/取消。
- **传输队列滞留记录可清除**：普通「需要重新检查」的任务行现在也提供「更多操作」菜单，内含「取消任务」，配合 v1.1.10 的冲突三操作，任何滞留记录都有出口。

## 说明

- 从 v1.1.10 升级后，传输队列里遗留的同名冲突记录点一次「重新检查」即可了结；也可以在任务行菜单里直接选择处理方式。
- 平台与校验同 v1.1.10：macOS（Apple Silicon）与 Linux x86_64 AppImage 均支持应用内自动更新，全部资产附 SHA256SUMS 与 minisign 签名。
