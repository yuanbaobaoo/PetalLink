# PetalLink v1.2.0

> 迭代方案与取证过程见 `docs/2026-11-22-同步队列与上传可靠性迭代方案.md`。

## 修复（同步正确性）

- **收尾响应缺 `size` 不再把成功的上传判成失败**：华为收尾 2xx 有时只回 `id`/`fileName`，旧逻辑把缺失的 `size` 读成 0，与本地长度比对必然不等，于是 25 个已经传完的文件被逐个判成「云端响应异常」并转入核验。现在区分「字段缺失」与「显式回填 0」：缺失时按本地已发送长度补全并留一条 WARN，显式长度不一致仍然拒绝。
- **分片范围出现空洞时只补缺失区间**：`rangeList` 从「必须从 0 连续」改为「连续前缀 + 首个空洞」，服务端漏收一段时回退到空洞起点重发，而不是整份重传；同一会话连续回退超过 3 次才判定会话失效并重建。
- **收尾元数据未就绪时继续轮询**：对象身份已经返回但元数据尚未生成的 2xx 不再立刻判歧义，改为在同一会话上继续轮询，窗口从 5×3 秒扩大到 10×5 秒（约 50 秒）。
- **上传 4xx/5xx 落响应体**：403 这类只能靠响应体区分的失败，现在会记录状态码、错误码与截断后的响应体，并按配额/风控/权限归类；终态策略未变。
- **核验判定「未提交」后不再在同步周期里重传**：重放改为投递到执行通道后台运行，核验通道立即返回。这是「正在确认结果卡十几分钟」的直接原因——一个 GB 级重放会占死唯一的同步周期，其它任务的核验全部排队。
- **缺少创建时间的同名候选不再一律判歧义**：单个候选时补查一次权威元数据再判定，不再空等 60 秒 × 60 次。
- **文件哈希按「路径 + 大小 + 修改时间」缓存**：同一文件的多轮核验不再重复整盘读取，缓冲区从 64KB 提升到 1MB 并放到阻塞线程池执行。
- **失败一定看得见**：新文件首次上传失败时 `sync_items` 还没有对应行，旧逻辑只做 UPDATE 会把失败彻底吞掉；现在补写一条 FAILED 记录，文件视图与列表都能看到。
- **重试预算从 31 秒扩到约 1.7 小时**：旧曲线是 1/2/4/8/16 秒、共 5 次，秒级抖动就会把任务打到终态失败。现在按 30s / 2m / 10m / 30m / 1h 推进，并叠加 0～20% 的任务级抖动，避免一批任务在同一秒集体重试。
- **等待网络不再可能永久停滞**：转入等待网络时会记下 60 秒的兜底复查时间，恢复调度据此唤醒；网络边沿不再是唯一唤醒条件。
- **自动重规划不再重置重试预算**：只有用户点击的「重试」才开启新一轮预算，熔断不会被每轮规划反复清零。
- **已确认云端写入的失败行继续占住路径**：避免同路径的删除/移动绕过一条「云端已写入、本地未结算」的记录。
- **可恢复失败不再丢失同步意图**：网络/限流/5xx 失败会把本轮请求位放回，下一次调度继续消费；只有确定性错误才结束本次请求。
- **登录改为应用内浮层**：点「使用华为账号登录」后，华为登录页以近满窗的圆角卡片从底部滑入（类似平板的 sheet），带标题区、关闭按钮与可点击遮罩，不再弹独立窗口。原生登录页与标题区严格对齐（标题区 56px 单行、上方两角 18px 圆角、底部贴住窗口下沿、窗口缩放实时跟随）；登录页不持久化任何 Cookie（每次都要输账号密码）；如果华为拦截内嵌页面，抽屉标题栏的「浏览器打开」可以继续同一次授权流程，回调仍回到应用。
- **云端删除增加四道防误删闸门**：本地扫描为空而基线非空（挂载卷未挂载、目录被清空、权限变化）、单轮删除超过 100 个条目、本地仍存在（含占位符）、以及规划到执行之间路径恢复——任何一种情况都会拒绝删除并降级为跳过。批量删除必须由用户在状态条上二次确认后才会执行，这是为了防止「本地看不见」被误当成「用户删除」而清空云端。
- **失败路径不再每分钟撞回来**：已终态失败的路径会被规划阶段直接跳过（每周期最多一条汇总告警），不再产生每天上万条「该文件正在执行其他同步任务」。
- **修复整机死锁**：远端核验在持有数据库锁时调用状态发布，回调再次获取同一把不可重入锁，触发后引擎、FUSE 与界面一起挂起。现在事务与发布严格分离。

## 修复（交互）

- **重试不再互斥**：行级「重试」只在这一条请求提交期间显示 loading（毫秒级），任意多行可以连续点击；后端只做静态校验与入队，稳定性检查移到后台执行。重复点击同一条返回「已在队列中」而不是报错。
- **新增「重试全部」**：传输弹层在有可重试失败项时显示汇总条，一键把全部失败项加入队列并立即返回汇总；状态条的失败详情弹窗也提供「重试全部」与单条「重试」。
- **「双端对齐」不再报「有同步任务进行中」**：点击只产生一条排队作业，由后台 worker 串行执行；传输弹层新增「目录同步」分区，显示排队中 / 正在规划 / 已投递 N 项 / 失败，并可取消。
- **托盘菜单不再自己关掉**：旧实现每 5 秒（且进度一变）就替换整个 `NSMenu`，macOS 会立即结束菜单追踪，表现为「刚点开就没了」。现在菜单结构固定，传输段就地插入/移除，进度只更新一行汇总文本；tooltip 同步显示当前汇总。托盘图标与兜底图标都做非零尺寸校验，避免再次触发 `ZeroWidth` panic。
- **大目录不再只显示前 100 项**：目录列举与搜索都改为后端自动翻页取全量，底部文案由「已全部加载」改成「共 N 项」。此前目录超过一页时，后面的文件在界面里根本不存在。
- **排序偏好会记住**：名称/大小/修改时间的排序与方向写入配置，下次启动保持同一视图；写入走独立命令，不与设置页保存互相覆盖。
- **同步周期不再等传输完成**：上传/下载改为「准入入队 + 后台执行」，周期只做规划与结构动作，30GB 批量上传期间自动刷新不再断档。
- **大目录只渲染可视区**：文件列表超过 200 行后按固定行高窗口化渲染，千级目录滚动不再卡顿；小目录行为与以前完全一致。
- **传输队列能筛选、能看速率、能看详情**：顶部按「全部/进行中/需要处理/已结束」过滤；运行中显示速率与剩余时间；失败、需重试与核验中的行可展开诊断信息（错误分类、尝试次数、下次重试、复制诊断）。
- **冲突提示可直接处理**：状态条「冲突 N」可点击，弹窗内直接给出覆盖远端 / 保留两者 / 取消三选一，不必再去传输队列里翻。
- **窗口不在前台也能看见失败**：同步状态把失败数同步到 Dock 角标。
- **文件列表支持快捷键**：Cmd/Ctrl+A 全选、Esc 取消多选、Delete 删除选中、Enter 打开、F2 重命名、空格切换勾选；搜索支持 Cmd/Ctrl+F 聚焦，并可切换「当前目录 / 整个云盘」范围。
- **搜索失败不再伪装成「无匹配结果」**：失败时显示错误横幅与重试按钮。
- **核验有了自己的通道**：远端核验过去只搭「启动 / 网络恢复 / 退避到期」这几趟车，机会稀少时要排很久；现在独立 10 秒扫描一次，不再和规划、传输抢同一个执行通道。
- **上传前置校验不再排队**：稳定性检查只锁自己的追踪表，3 秒稳定窗口在锁外等待，6 路并发上传的校验可以真正并行。
- **分片上传少了一份整块拷贝**：请求体改为引用计数缓冲，10MB 分片不再每片多复制一份；下载产物的整文件 SHA-256 也挪到了阻塞线程池。
- **目录同步补建目录更快且不产生重复目录**：同一父目录的子项遍历在 5 秒窗口内复用，一趟目录对齐里 N 次全量翻页压到 1 次；遍历失败时宁可不创建，也不冒重复目录的风险。
- **入队不再整表扫描**：同路径仲裁改为按索引点查，批量上传 1000 个文件不再是 O(n²) 全表扫。
- **同步周期少两次全量深拷贝**：本地/云端快照直接移入 planner 快照，27k 文件目录每周期省掉两份完整克隆。
- **批量释放空间改为 4 路并发**，不再逐个等待；路径恢复的基线也改为只读一次。
- **token 刷新不再阻塞异步线程**：机器标识进程内缓存（不再每次加解密都起 `ioreg`），token 持久化移到阻塞线程池。
- **大批量状态查询不再卡住引擎**：文件列表的批量同步状态改成「锁内只读库、锁外批量 stat/xattr」，大目录下不再让引擎写库一起排队。
- **「正在确认结果」分阶段显示**：有计划重试时间时显示倒计时「等待重试确认（N 秒）」，反复确认时显示「正在确认结果（第 N 次）」，用户能区分「在跑」和「在等」。
- **文件列表能直接看到同步状态**：状态列从四态扩展为六态（文件夹 / 已同步 / 仅云端 / 正在同步 / 正在确认结果 / 同步失败），任务开始与结束各刷新一次，不再需要去传输队列里猜。
- **同步提示不再互相覆盖**：Toast 从「后一条顶掉前一条」改为最多同屏 3 条的队列，批量失败不会只剩最后一条。
- **批量下载改为入队即返回**：不再逐个等待下载完成，提示区分「已下载 n 项 / n 项已加入传输队列 / n 项失败（首条原因）」。
- **按需下载不再把「已入队」显示成红色失败**：新增 `sync_download_on_demand` 的结果枚举，已入队时提示「完成后可打开」。
- **空目录与加载失败分开显示**：加载失败时不再同时出现「此文件夹为空」，改为错误态并给出「重新加载」。
- **静默刷新不再把列表弹回顶部**：同目录刷新保留滚动位置；切换目录（含同级跳转）才回到顶部并清空勾选。

## 数据库

- schemaVersion 6 → 7：新增 `folder_sync_jobs`（含状态索引与活跃作业唯一索引）与 `idx_sync_items_local_path`。只新增、不改列；降级到旧版本时旧版本忽略新表即可运行。

## 工程

- 安全加固：日志导出只接受 `.log`/`.txt` 普通文件路径并流式写入（不再整包进内存、不再可覆盖任意文件）；OAuth 回调页的失败原因按 HTML 文本转义，消除反射型脚本执行。
- 新增/扩充测试：收尾 `size` 容忍与范围空洞解析、重试入队幂等与一键重试汇总、核验重放入队而不内联执行、失败补写基线、失败路径过滤、v7 迁移与作业队列 FIFO/取消、前端并行重试、Toast 队列、目录/搜索全量分页。
- `TaskRunner` 新增「只入队不执行」入口（`enqueue`），目录同步、按需下载入队与核验重放共用同一准入合同。
